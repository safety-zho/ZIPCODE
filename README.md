# 우편번호 일괄 입력

주소가 들어 있는 엑셀(.xlsx)을 올리면 주소마다 **행정안전부 도로명주소 검색**으로 우편번호를 찾아 우편번호 칸을 채운 새 엑셀을 내려받는 웹 도구입니다. 설치 없이 링크로 열어서 씁니다.

```
엑셀 올리기 → 주소 열·우편번호 열 확인 → 우편번호 조회 → (후보가 여럿이면 선택) → 엑셀 내려받기
```

## 동작 방식

- 화면 전체가 GitHub Pages의 정적 페이지입니다. 별도 서버가 없습니다.
- **엑셀 파일은 브라우저 안에서만 처리**되고 어디에도 올라가지 않습니다.
- 행정안전부 도로명주소 검색 API(`business.juso.go.kr`)로는 주소 중 **시·군·구 + 도로명 + 건물번호**(지번 주소는 **동·리 + 지번**)만 보냅니다. 동·호수, 층, 괄호 안 내용, 이름 등 주소 칸의 나머지 글자와 다른 열은 보내지 않습니다.
- 우편번호는 검색 결과에서만 가져옵니다. 화면에 우편번호 입력칸이 없고, 후보가 여럿이면 검색 결과 중에서 고르게 합니다.
- 검색한 `도로명 + 건물번호`(또는 `동 + 지번`)가 결과 주소에 실제로 들어 있는 후보만 씁니다. 맞지 않는 결과는 버리고 ‘조회 오류’로 표시합니다.
- 결과 파일은 원본에서 우편번호 칸(과 선택한 확인용 열)만 바꿉니다. 서식·수식·병합·다른 시트는 그대로이며, 우편번호는 글자로 저장되어 `06232`의 앞자리 0이 유지됩니다.

5자리 우편번호는 행정안전부가 정하는 국가기초구역번호를 그대로 쓰므로, 일반 주소는 인터넷우체국 검색 결과와 같은 값입니다. 각 행의 **우체국에서 보기**로 인터넷우체국 결과와 맞춰 볼 수 있습니다.

## 주소 검색 규칙

주소 칸에서 검색에 필요한 부분만 뽑아 검색합니다. 우편번호는 건물 단위로 정해지므로 동·호수가 없어도 정확히 찾습니다.

| 엑셀 주소 | 보내는 검색어 (순서대로) |
|---|---|
| `서울 강남구 테헤란로 123, 5층 501호 (역삼동)` | `서울 강남구 테헤란로 123` → `테헤란로 123` |
| `강남구 역삼동 648-23 101동 202호` | `강남구 역삼동 648-23` → `역삼동 648-23` |
| `래미안아파트 101동 202호` (도로명·지번 없음) | `래미안아파트` |

시·군·구를 뺀 검색어로 찾으면 원래 주소의 시·군·구로 후보를 거릅니다. 후보의 우편번호가 모두 같으면 자동으로 채우고, 서로 다르면 **선택 필요**로 표시합니다. 화면에서 검색어를 고쳐 다시 검색할 때도 같은 규칙으로 동·호수를 뺍니다.

## 엑셀 파일

- `.xlsx`만 지원합니다(`.xls`는 엑셀에서 ‘Excel 통합 문서(.xlsx)’로 저장 후 사용).
- 위쪽 30행 안에서 `주소`, `도로명주소`, `소재지` 같은 제목을 찾아 주소 열로 잡습니다. `상세주소`, `이메일주소`는 제외합니다. 화면에서 바꿀 수 있습니다.
- `우편번호` 열이 없으면 오른쪽 끝에 새 열을 만듭니다.
- 한 번에 최대 5,000건까지 처리합니다.

## 관리

### 승인키 바꾸기

`config.js`의 `jusoKey`에 행정안전부 도로명주소 검색 API 승인키를 넣습니다. 승인키는 [business.juso.go.kr](https://business.juso.go.kr)에서 무료로 발급받으며, 서비스 URL은 `https://safety-zho.github.io`로 등록합니다.

승인키는 페이지 코드에 들어가므로 누구나 볼 수 있습니다. 주소 검색 전용 무료 키라 노출돼도 피해는 거의 없고, 문제가 생기면 재발급해 바꾸면 됩니다. 개발용 승인키는 기간이 있으니 운영용으로 바꿔 두세요.

### 배포

`main` 브랜치에 올리면 GitHub Pages가 자동으로 반영합니다(저장소 Settings → Pages → Deploy from a branch → `main` / `(root)`).

### 시험

```bash
node --test tests/*.test.js
```

```
tests/              자동 시험
```
