# 우편번호 일괄 입력

주소가 들어 있는 엑셀(.xlsx)을 올리면 주소마다 **인터넷우체국에서 검색한 우편번호**를 우편번호 칸에 채워 새 엑셀 파일로 내려받는 웹앱입니다.

```
엑셀 올리기 → 주소 열·우편번호 열 확인 → 우편번호 조회 → (후보가 여럿이면 선택) → 엑셀 내려받기
```

## 우편번호가 인터넷우체국 값만 들어가는 방식

1. **검색 결과에서만 가져옵니다.** 서버가 주소로 인터넷우체국을 검색하고, 거기서 돌려준 5자리 우편번호만 후보로 씁니다.
2. **화면에 입력칸이 없습니다.** 결과가 하나면 자동으로 채우고, 여럿이면 검색 결과 목록에서 고르게 합니다. 결과가 없으면 검색어를 고쳐 다시 검색할 수만 있습니다.
3. **파일에 쓰기 전에 서버가 한 번 더 확인합니다.** 조회 결과마다 서버 비밀키로 서명을 붙이고, 엑셀에 쓰기 직전 서명을 검증합니다. 브라우저에서 값을 바꿔 보내도 저장되지 않습니다.
4. 확인되지 않은 행의 기존 우편번호는 기본적으로 비웁니다(화면에서 끌 수 있음). 결과 파일의 우편번호 열에는 조회로 확인된 값만 남습니다.

우편번호는 텍스트로 저장되어 `06232`처럼 앞자리 0이 사라지지 않습니다. 원본 파일의 서식(글꼴, 색, 테두리, 열 너비 등)은 그대로 두고 값만 바꿉니다.

## 설치와 실행

**인터넷(인터넷우체국)에 접속할 수 있는 PC**에서 실행해야 합니다.

### 방법 1. 실행 파일(.exe) — 구청 PC 권장

Python 설치 없이 `ZipcodeFiller.exe`를 두 번 누르면 검은 창이 뜨고 브라우저가 자동으로 열립니다. 검은 창을 닫으면 프로그램이 끝납니다. 파일 이름은 `우편번호일괄입력.exe`처럼 바꿔도 됩니다.

.exe는 아래 둘 중 한 가지로 만듭니다(한 번만 만들어 여러 PC에 복사).

- **GitHub로 자동 생성**: 이 폴더 전체를 GitHub 저장소에 올리면 `.github/workflows/build-exe.yml`이 GitHub의 Windows 서버에서 .exe를 만듭니다. 저장소 → Actions 탭 → 최근 실행 → Artifacts의 `ZipcodeFiller-windows`를 내려받습니다(보관 90일).
- **Windows PC 한 대에서 생성**: Python이 설치된 Windows PC에서 `build_exe.bat`을 두 번 누르면 `dist\ZipcodeFiller.exe`가 만들어집니다.

처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 `추가 정보 → 실행`을 누릅니다. 백신이나 기관 보안 정책이 실행을 막으면 전산 담당자에게 실행 허용을 요청하세요(직접 만든 프로그램이라 정식 서명이 없어서 생기는 경고입니다).

### 방법 2. Python으로 실행

Python 3.10 이상이 필요합니다.

**Windows**: `run_windows.bat`을 두 번 누릅니다. 처음 한 번은 필요한 프로그램을 설치하고, 이후에는 바로 브라우저가 열립니다.

**macOS / Linux**:

```bash
./run.sh
```

직접 실행하려면:

```bash
pip install -r requirements.txt
python app.py        # http://127.0.0.1:8000
```

같은 망의 다른 직원도 쓰게 하려면 `.env`에 `HOST=0.0.0.0`을 넣고, 다른 PC에서 `http://<이 PC의 IP>:8000`으로 접속합니다.

## 조회 방식 고르기 (`.env`)

`.env.example`을 `.env`로 복사해 설정합니다.

| 방식 | 설정 | 특징 |
|---|---|---|
| 인터넷우체국 검색 화면 | `EPOST_MODE=web` (기본값) | 질문에 첨부한 인터넷우체국 우편번호 검색과 같은 결과. 인증키 없이 바로 사용 가능 |
| 우정사업본부 공식 API | `EPOST_MODE=api`<br>`EPOST_SERVICE_KEY=발급받은키` | 우정사업본부가 공공데이터포털로 제공하는 공식 조회 서비스. 화면 구조가 바뀌어도 영향이 없어 **정식 운영에 권장** |

- 공식 API 인증키: 공공데이터포털 [도로명주소 우편번호 조회 서비스](https://www.data.go.kr/data/15000124/openapi.do)에서 활용신청(자동 승인). 개발계정은 하루 10,000건이며, 운영계정으로 바꾸면 늘릴 수 있습니다.
- `web` 방식은 인터넷우체국 화면의 HTML을 읽기 때문에, 우체국이 화면 구조를 바꾸면 조회가 되지 않을 수 있습니다. 이때는 `api` 방식으로 바꾸거나 `epost.py`의 `parse_web_results`를 고칩니다.
- 우체국 서버에 부담을 주지 않도록 요청 사이에 0.3초 간격을 둡니다(`EPOST_MIN_INTERVAL`). 같은 주소는 한 번만 조회합니다.

## 주소 검색 규칙

엑셀 주소를 그대로 검색하고, 결과가 없으면 아래 순서로 검색어를 줄여 다시 찾습니다.

1. 원문: `서울 강남구 테헤란로 123, 5층 (역삼동)`
2. 괄호·쉼표 뒤 상세주소 제거: `서울 강남구 테헤란로 123`
3. 도로명 + 건물번호만: `테헤란로 123` → 원문에 있던 시·군·구(`강남구`)로 후보를 거름

지번 주소(`역삼동 648-23 101동 202호` → `역삼동 648-23`)도 같은 방식으로 처리합니다.

후보의 우편번호가 모두 같으면 자동으로 채우고, 우편번호가 서로 다르면 **선택 필요**로 표시해 담당자가 고르게 합니다. 시·도, 시·군·구가 없는 주소(예: `남부순환로 2620`)는 같은 도로명이 여러 지역에 있으면 선택 필요가 될 수 있습니다.

## 엑셀 파일 형식

- `.xlsx`만 지원합니다. `.xls`는 엑셀에서 ‘다른 이름으로 저장 → Excel 통합 문서(.xlsx)’로 바꿔 주세요.
- 위쪽 30행 안에서 `주소`, `도로명주소`, `소재지` 같은 제목을 찾아 주소 열로 잡습니다. `상세주소`, `이메일주소`는 제외합니다. 화면에서 다른 열로 바꿀 수 있습니다.
- `우편번호` 제목의 열이 없으면 오른쪽 끝에 새 열을 만듭니다.
- 시트가 여러 개면 화면에서 고를 수 있습니다.
- 한 번에 최대 5,000건(`MAX_ROWS`)까지 처리합니다.

## 개인정보

- 올린 파일은 서버 메모리에서만 처리하고 디스크에 저장하지 않습니다.
- 주소는 우편번호 검색을 위해 인터넷우체국(우정사업본부)으로만 전송됩니다.
- 서버 기록(로그)에는 파일 이름과 처리 건수만 남깁니다.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 모든 행이 ‘조회 오류’ | 실행 중인 PC에서 브라우저로 인터넷우체국이 열리는지 확인. 프록시가 있으면 `HTTPS_PROXY` 환경변수 설정 |
| 보안 연결(SSL) 오류 | 기관 보안장비가 인증서를 바꾸는 환경이면 기관 인증서 파일 경로를 `REQUESTS_CA_BUNDLE` 환경변수로 지정 |
| 모든 행이 ‘결과 없음’ | 인터넷우체국 화면 구조가 바뀌었을 수 있음. `.env`에 `EPOST_DEBUG_DIR=debug`를 넣고 다시 조회하면 받은 원문이 `debug` 폴더에 저장됨. 또는 `EPOST_MODE=api`로 전환 |
| API 방식에서 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` | 인증키 오타 또는 활용신청 직후(반영까지 최대 1~2시간) |
| 내려받을 때 ‘확인되지 않은 우편번호’ 오류 | 조회 후 서버가 다시 켜진 경우. 다시 조회하거나 `.env`에 `APP_SECRET` 지정 |

## 파일 구성

```
build_exe.bat     Windows PC에서 .exe 만들기
.github/workflows GitHub에서 .exe 자동으로 만들기
app.py            웹 서버 (화면, 업로드, 조회, 내려받기)
epost.py          인터넷우체국 조회, 검색어 만들기, 결과 서명
excel_io.py       엑셀 열 찾기, 우편번호 쓰기
static/index.html 화면
tests/            자동 테스트 (python -m unittest discover -s tests)
```
