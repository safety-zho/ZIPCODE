우편번호는 인터넷우체국(우정사업본부) 검색 결과에서만 가져오며, 직접 입력할 수 없습니다. 후보가 여러 개인 주소는 검색 결과 중에서 골라 주세요.

올린 파일은 서버에 저장하지 않습니다. 주소는 우편번호 검색을 위해서만 인터넷우체국으로 전송됩니다.
